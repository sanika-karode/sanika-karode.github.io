Emote: ML Facial Recognition

View on GitHub Watch Full Demo

Project Overview

Developed during HackGT 2024, Emote is a machine learning-based tool designed to help children with autism identify facial expressions. By using the Deepface library, we co-developed a system that captures live images and provides instant emotional feedback.

Machine LearningDeepface, Jupyter Notebook
Computer VisionOpenCV (cv2)
DeploymentGoogle Colab, Wix

Technical Approach

  • Real-time Detection: Implemented a live camera feed using OpenCV with custom keyboard triggers for taking photos and resetting the system.
  • ML Pipeline: Integrated pre-trained emotion recognition models to analyze facial features and display bounding boxes with dominant labels.
  • Stability: Optimized frame buffers and wait-key timing to resolve system latency and "spinning" issues during real-time processing.

Future Vision

The next iteration of Emote moves the software from a computer screen to Augmented Reality (AR) glasses. Our goal is to provide real-time social cues in the user's natural environment, labeling emotions directly over people's faces as they interact.
