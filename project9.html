Ascend: Intelligent Route Optimization for Climbers

View on GitHub Watch Full Demo

Project Overview

Ascend is a full-stack intelligent route-analysis platform that helps climbers determine the most efficient path up a rock wall. Users upload a photo of a wall, select holds, and input personal metrics such as height and experience level. The system then computes a personalized, physically feasible climbing route using graph-based optimization.

Built With Python, NetworkX, FastAPI, React, Vite, PostgreSQL, SQLAlchemy
Core Algorithm A* Search (Graph Optimization with Dynamic Hand-State Modeling)

Technical Architecture

Ascend was architected as a modular three-layer system:

  • Frontend: Built with React and Vite, enabling users to upload wall images, select holds, and input body metrics through an intuitive UI.
  • API Layer: FastAPI backend handling validation, structured communication, and database interactions.
  • Graph Intelligence Engine: Python-based engine using NetworkX to model climbing routes as weighted graphs and compute optimal paths using A* search.

Graph Modeling Approach

Each hold is modeled as a node in a graph, with edges representing possible movements between holds. Edge weights are dynamically calculated based on Euclidean distance, hold type, arm span constraints, and movement feasibility. Unlike a simple shortest-path model, the algorithm tracks left and right hand placements to simulate realistic climbing motion.

Challenges & Engineering Decisions

  • Abstracting real human movement into measurable computational constraints.
  • Managing complex Git merges and schema conflicts during backend integration.
  • Balancing model realism with computational efficiency during optimization.

Outcomes & Impact

We successfully delivered a fully working prototype during Hacklytics 2026. The system was tested on a real climb at the CRC, validating our graph-based modeling approach in a real-world environment. Ascend demonstrates how physical sports can be translated into computational optimization problems, bridging biomechanics and AI.
